# 3part
## Игра по книги "1984"
В третей части главный герой данного романа оказывается в результате задержание в Министерстве Любви, задача игрока, как раз
и заключается в побеге из этого места. Игрок может перемещатся, собиарть предметы, и с помощью этих предметов взаимодействовать с миром, 
в игре есть два вида персонажей `C` и `N`, первые соответсвенно приченяют вред, а со вторыми можно разговаривать, и узнавать информацию о мире.
Игра представляет собой консольную программу, использующую ANSI Escape-коды, которые могут работать не везде (Windows 10 (начиная с обновления 1607) и Windows 11, macOS, Linux - полная поддержка).
Игра находится в стадии разроботке, но основные игровые функции уже реализованы. Сборка игры предусмотрена с помощью СMake.
